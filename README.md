# 学鹭伴学 · 在线演示

**在线地址：** https://emocow-liuyun.github.io/xuelu-demo/

家长 / 大学生 / 机构 / 接送四端的完整界面演示，含课程与套餐、伴学排期预约、
校车线路、入驻流程、我的订单、考公考研考编与高考学业规划。

## 说明

- 本站是**纯静态演示**：业务数据来自构建时导出的真实接口快照，随仓库一起发布。
- 没有后端服务，不连接任何数据库；下单、入驻、评价、反馈等写操作只作用于浏览器内存，刷新即还原。
- 登录 / 注册不可用（演示站无账号体系），打开后选择身份即可用游客身份浏览全部页面。
- 手机号等字段已统一脱敏为 `13800000000` 这类演示号码，不包含任何真实个人信息。
- 考公 / 考研 / 考编 / 高考数据仅用于界面与交互演示，不作为真实报考或升学依据。

## 目录

| 文件 | 作用 |
| --- | --- |
| `index.html` | 入口，加载 `demo-boot.js` |
| `demo-boot.js` | 先装 fetch 拦截层，再加载原前端 bundle |
| `demo-api.js` | 浏览器内复现源站 `server.mjs` 的接口协议 |
| `demo-data.json` | 业务数据快照（已脱敏） |
| `demo-model.js` | 考公 / 考研 / 考编 / 高考模型（由源码打包而来） |
| `app.bundle.js` `all.css` | 原项目前端产物，未改动 |

完整源码与可运行后端在私有仓库 `xuelu-education-platform`。
